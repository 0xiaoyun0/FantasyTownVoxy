# Fantasy Town Voxy 0.0.3（公开测试版） · NeoForge 1.21.1

基于你提供的 NeoVoxy 0.6.1 和 VSS 0.3.5，合并为一个 JAR。客户端和服务器使用同一文件，服务器安装可选。本版修复 `Too many replacement sections: 65`，提供旧 LOD 导入、钠内统一中文面板、远程管理员设置和配置热更新。0.0.1 修复重进后 LOD 目录漂移，增加 Xaero 后端存储隔离、每日下载时段和双重带宽限制；详见 `CHANGELOG.md`。

## 安装与升级

使用 `fantasy-town-voxy-0.0.3-neoforge-mc1.21.1.jar`，替换旧 Voxy / NeoVoxy / VOXY-HXZ，并移除单独的 VSS，避免重复安装。

- 客户端：Minecraft 1.21.1、Java 21、NeoForge、Sodium 0.8.12 或兼容版本。
- 服务器：无需 Sodium、Iris、Fabric 或 Connector。更新服务器 JAR 后，服务端崩溃修复才生效。
- 超过 64 个区段的地形共享需要两端都更新。旧客户端仍可连接，但不接收它不能解码的高区段列。
- RTF / NeoTerraForged 仍独立安装；本 JAR 保留其 VSS 适配，没有打包整个地形模组。

本次没有部署到正式客户端或服务器。测试使用工程 `build` 下的隔离副本。

## 统一操作面板

游戏内输入 **`/voxyhxz menu`**，或从模组列表配置按钮进入。

所有设置都直接位于 **钠的视频设置 → Fantasy Town Voxy**。命令和模组列表按钮也打开这个界面。使用钠原生的分类、搜索、滑块、开关和应用按钮，导入、热重载与管理员操作也在里面，不再打开单独的控制面板。选项提供中文名称、单位和悬停说明。

## 渲染方式

**新配置默认“NeoVoxy 原版”。** 旧配置中明确保存的选择会保留。要切回原版，选择“基本显示 → 渲染方式 → NeoVoxy 原版”，或执行：

```text
/voxyhxz profile original
```

现在画面模式与性能调度分别控制。**默认 NeoVoxy 画面 + 开启性能调度**：保留 NeoVoxy 粗模型回退，同时按负载渐进加载、调节视距及资源预算。上述 `/voxyhxz profile original` 命令会同时选择原版画面并关闭性能调度；只在面板切换画面不改变调度。VSS 共享、预测、世界隔离和服务端防护独立保留。

“HXZ 可调优化”提供有限视野外准备、过大粗模型限制、近处细化等画面选项；渐进加载和最低 30 FPS 反馈目标在两种画面下均可用。下列兼容命令还会套用整套 HXZ 预设：

```text
/voxyhxz profile balanced
/voxyhxz profile smooth
```

balanced 在视野外少量准备粗模型；smooth 按距离准备细节，每秒最多 8 个后台请求，减少转身等待但增加占用。HXZ 通常从约 512 方块开始，缓冲 5 秒后逐步扩展。30 FPS 是调度目标，不能保证其他模组、光影及硬件在任何场景都达到该帧率。

HXZ 默认几何缓冲 512 MiB、空闲区段缓存 64 MiB、专用后台线程最多 2 个，均不是整个游戏的资源上限。真实数据保留 NeoVoxy 正常 LOD 层级，HXZ 可限制投影过大的回退模型。预测默认开启“LOD 画质优先”，仅显示完整 64×64 网格且采样间距不超过 2 格的结果；粗山坡与柱状块不再占位。远处可能等待更久或暂不显示，可在钠“地形预测”页关闭此策略。性能预设保留该选择。

“性能与加载”提供低端、均衡、高端三个可继续编辑的预设，保留画面模式、最大视距和世界身份设置；也可执行 `/voxyhxz performance low`、`balanced` 或 `quality`。稳定限帧恰好等于目标帧率时，控制器会小步尝试扩大视距；负载上升后回退并冷却，避免一直停留在初始范围。

“视野外剔除”决定是否剔除不可见节点，“视野外预加载”决定背后地形准备到什么程度。要关闭 HXZ 遍历阶段的视野外剔除，在“HXZ 画面优化”关闭对应开关。原版 NeoVoxy 自身也有视锥及遮挡剔除。

## 导入旧 Voxy / 已生成 LOD

1. 进入接收数据的世界和维度，打开“导入 LOD”。
2. 选择“旧 Voxy / NeoVoxy LOD 文件夹”，选择包含 `CURRENT` 的数据库文件夹；手动输入 `CURRENT` 文件路径也可以。
3. 确认源数据属于当前世界、当前维度，再开始。

支持所提供旧 Voxy 0.2.15 / NeoVoxy 的 SaveLoadSystem3 v0 RocksDB 数据。先只读检查源库、区段和映射，再按当前客户端重映射方块/群系编号，分批写入最高精度区段并重建上层 LOD。不直接沿用源库数字编号，也不修改源文件。

可关闭面板继续游戏，可取消；离开目标世界也会取消。**已导入部分保留，相同坐标的目标 LOD 会被替换**，建议先备份目标缓存。缺失模组方块以空气代替并报告数量。请关闭仍写入源库的旧客户端；多世界目录必须选定一个具体数据库，不按相同种子自动合并。

其他入口：

- Minecraft / Bobby：选择直接包含 `r.x.z.mca` 的 region 文件夹。
- Minecraft region ZIP：选择单维度压缩包；多维度包在路径后加 `!/region` 或 `!/DIM-1/region` 指定内部目录。
- Distant Horizons SQLite：沿用原导入器，需要环境已有 SQLite JDBC / LZMA；本版不额外捆绑，缺少时会提示。

只含粗层级、损坏、缺失映射或其他数据库格式会被拒绝，不能保证任意软件的“LOD 文件”均可导入。独立 VSS `.vcl` 传输缓存不属于此旧库导入格式。

命令：`/voxyhxz importlod <路径>`；取消：`/voxy import cancel`。

## 管理员与热更新

钠内的“管理员”页由服务器核验 **OP 等级 2**，普通玩家不能绕过权限。进入“共享与地形、负载保护、下载限制、传输与缓存、高级参数”任意分组，先点 **“读取 / 刷新服务器配置”**；服务器回复前不显示可编辑的数值。读取后显示服务器实际值。其他管理员已修改配置时，旧提交被拒绝，刷新后重试。

点击钠的“应用”批量提交，随后在“查看服务器状态与操作结果”确认服务器回复。刷新服务器值不会丢弃客户端草稿；重新读取前若有服务器草稿，会询问是否放弃。服务器项的重置操作返回最近读取值，不恢复出厂值。“从文件热重载服务器配置”读取磁盘文件；“恢复因异常暂停的 LOD 服务”清除异常暂停，不会强行打开管理员关闭的共享。

```text
/voxyhxzserver status
/voxyhxzserver sharing off
/voxyhxzserver sharing on
/voxyhxzserver prediction off
/voxyhxzserver prediction on
/voxyhxzserver reload
/voxyhxzserver safety status
/voxyhxzserver safety set columnsPerTick 8
/voxyhxzserver safety set columnsPerPlayerTick 2
/voxyhxzserver safety reset
```

客户端用“状态与热更新 → 从文件热重载客户端配置”或 `/voxyhxz reload`。**不是自动监视文件**；UI 应用、命令或按钮触发更新。需要更换缓存/渲染器的参数会重建远景，可能短暂停顿；旧 LOD 导入期间推迟重建。配置格式错误时，重载保留当前运行设置。

服务器身份、节点身份、共享世界身份关系需重启后生效，不允许在线混用缓存；不在远程修改白名单中。

## 崩溃修复与保护

报告运行的是旧 **0.2.15-hxz.2**。VSS 把合法的 65 区段地形列当成超出 64 的非法数据，异常从发送流程传播到服务器 tick。后续 watchdog 报告与主线程退出后的停服过程相符；不能仅凭 watchdog 文件认定直接原因是请求洪峰。

本版同步修改载荷、拆包、客户端解码、磁盘缓存和存在性缓存，支持最多 255 区段，符合当前缓存计数上限；不截断成 64 个。数据长度、坐标、重复区段和原有分包上限仍校验。回归覆盖合法的 64、65、68、128、255 区段以及超限和重复区段。

服务端保护默认开启：全服每 tick 16 列、每玩家 4 列，队列全服 512 / 每玩家 64 列；磁盘、回调、发送、打包和缓存有界。连续慢 tick 或内存紧张时暂缓请求，普通共享异常会暂停 LOD 服务并记录原因。

新配置默认**共享已有地形开启、预测资料同步开启、LOD 请求生成新地形关闭、主动预读关闭**。旧配置保留，保护层仍限制实际用量。需要按请求生成新地形时，两项均须开启：

```text
/voxyhxzserver safety set allowLodGeneration true
/vss generation enable
```

默认 4 ms 是工作单元间的预算，不能中断已执行的模组调用。本版不关闭 watchdog，也不能保证抵御其他模组死锁、JVM/原生库故障或系统资源耗尽。完整说明见 `SERVER_SAFETY.zh-CN.md`。

## 多世界与 RTF

按服务器身份、后端节点身份和维度隔离缓存。不同 VL / Velocity 后端不要复制相同 `nodeIdentity`。无服务端身份时按稳定服务器地址保存，重进可复用原数据；同地址同种子的独立后端仍需要服务端身份；高级用户可在“数据与兼容”填写固定世界标识，独立世界须使用不同值。新缓存使用 `hxz-neovoxy-0.6` 子目录；通过导入迁移旧数据。

RTF 自定义预设、噪声和生成器依赖继续经 VSS 快照同步。实际区块渲染独立于预测。客户端“地形预测”与服务器“提供预测资料”分别开启；两端仍应安装匹配的 RTF 和数据包。

“按地形预设隔离预测缓存”默认开启，将生成器数据、注册表指纹、维度、高度和采样设置加入路径。旧的仅按种子保存的预测缓存保留，但不自动混入新路径；真实 Voxy LOD 和手动导入不受此缓存开关影响。

“数据与兼容”中的转服校验拒收旧连接数据，并在 Xaero 真正写入前核验地图任务所属会话；另有默认开启的“Xaero 跨服地图隔离”，在地图和路标开始读写前选定后端专用目录，A → B → A 回到 A 原目录；修改此项需重新进入服务器。旧地图保留，不自动合并；关闭隔离后重进可回到旧目录。“航空学存储区保护”通过 Sable 的 plot API 排除船体子空间，管理员端也有独立过滤开关；这不增加远处船体的物理模拟或移动船体 LOD。

实际 NeoTerraForged 0.0.6 测试将海平面 63 改为 66，经真实快照编码/解码比对完整预设；验证参数保留，不代表全部结构、洞穴与数据包均已逐方块验证。

## 0.0.1 下载管理

进入“管理员 · 下载限制”读取服务器配置，调整时段、时区、全服及个人上限并点击应用。默认时段关闭（预填 17:00–23:00、UTC+08:00），每人上限 131072 B/s 开启，全服 500000 B/s；旧全服上限保留。时段支持跨午夜，起止相同表示全天禁止。只限制 LOD 下载，不删除本地缓存。

```text
/voxyhxzserver downloads timezone +08:00
/voxyhxzserver downloads block 17:00 23:00
/voxyhxzserver downloads rate 512 128
/voxyhxzserver downloads off
/voxyhxzserver downloads player-limit-off
```

`rate` 单位是 KiB/s，面板单位是 B/s。`off` 只取消时段限制。服务器恢复允许下载后会重新通知在线玩家。独立大包受额度积累约束，短时流量可波动；原版区块、聊天和初次地形预测参数不计入此下载预算。

## 0.0.1 预测稳定性

钠“地形预测”页新增默认开启、可分别关闭的稳定预测、网格逐点采样、冰山/恶地补全。低模与精修共用地形和水面采样，RTF 初始化补齐噪声设置注册表；模式变化时分离预测缓存。实际 RTF FULL 区块对照方法、四组数据和剩余误差见 [PREDICTION_ACCURACY.zh-CN.md](PREDICTION_ACCURACY.zh-CN.md)。
