计时从到达测试位置开始，包含随后发生的预测初始化；不包含启动游戏和到达位置前的等待。首次合格/绘制由每秒采样发现，因此是观察时刻，存在采样和卡顿延迟。绘制证据要求窗口内新增 GPU 上传和渲染计数，并且合格快照非空；它不衡量整片视野的完成率、画面美观程度或与真实地形的准确率。

堆峰值为每秒采样的已使用 Java 堆，不含堆外内存、显存，也不是绝对瞬时峰值。帧间隔包含游戏、世界生成、GC、系统竞争和限帧影响，不是模组独占耗时，不能据此承诺所有电脑的 FPS。这是单场景单次运行，未建立统计显著性；不换算生成速度倍数。外形审计模式禁止混入正式结果。
