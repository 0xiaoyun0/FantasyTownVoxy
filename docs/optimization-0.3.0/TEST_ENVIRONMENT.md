| 物理内存 | 系统报告约 15.75 GiB |

性能对照的工作线程、距离、预设、视点与计时范围见 [BENCHMARK.md](BENCHMARK.md)。游戏/GPU 回归串行执行；其他系统和应用负载没有被强制关闭，也没有进行固定功耗或热状态控制。两版各一次正式窗口，不能据此推导显著的帧率、内存或吞吐倍率，更不能代表所有低端、高端电脑。

完整整合包的首次回归曾在 300 秒测试时限内尚未完成 JEI 初始化，被测试启动器终止；没有生成崩溃报告。其记录保留在本地验证目录。完整整合包启动器现单独允许 900 秒，以实际完成验证及正常退出为通过条件；这项启动等待调整不改变模组的生成、线程或画质预算。
